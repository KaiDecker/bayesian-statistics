# A4 Exam Reference

《贝叶斯统计》第一、二章考试速查纸。`main.tex` 为独立 LaTeX 入口，`main.pdf` 为两页 A4：一张纸的正、反面。该文件与课程笔记、板书电子转录、习题解答分别维护。

## Scope

按本次指定范围编排：常见分布及结论、Gamma/Beta 函数、教材五类共轭先验、三种信息、贝叶斯假设、后验加权关系与精度相加、后验估计及 MSE、常用充分统计量、倒 Gamma 与卡方变换及可信上限、后验预测步骤、假设检验三种情形。

共轭先验覆盖教材表 1.3.1 的二项、泊松、指数、正态均值和正态方差五类模型；为配合该表，常见分布同时列出泊松与指数。分布公式保留支持集、参数化方式及矩存在条件。MSE 明确区分后验误差和频率误差。

本版没有加入新的复习专题，例如超参数确定、正态与倒 Gamma 的联合先验、HPD 区间、似然原理；是否加入由用户决定。本版不宣称覆盖两章所有可能考点。

采用与课堂密度一致的 Gamma **率参数化**：`Ga(a,b)` 的密度为 `b^a x^(a-1) exp(-bx) / Gamma(a)`，均值为 `a/b`。教材部分文字称第二参数为“尺度”，本版按实际密度明确写成“率”，防止混用。

“贝叶斯假设”限定为教材成功概率的 `U(0,1)` 先验；不推广为所有参数都必须取均匀先验。所有可信限统一使用左侧概率分位数：`P(Y <= q_p) = p`。倒 Gamma 的可信上限使用卡方的 `alpha` 分位数，可信下限使用 `1-alpha` 分位数。

这是考试复习速查纸，公式按数学意义核对，不沿用板书电子转录中专为保真而保留的漏项或笔误。

## Build and print

Use XeLaTeX:

```sh
latexmk -xelatex -interaction=nonstopmode -halt-on-error main.tex
```

PDF 固定为两页、A4 纵向。黑白双栏，正文 9 pt，左右边距 9 mm，上下边距 8 mm。打印选择 **A4、实际大小 / 100%、双面、长边翻转**，不要设置“每张纸两页”，否则会把已经安排好的两个面再缩小。

该排版也可用作手抄时的分区参考。修改公式或字号后应重新确认页数为 2，且没有栏内溢出或缺字。
