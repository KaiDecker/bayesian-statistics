# A4 Exam Reference

《贝叶斯统计》第一、二章考试手抄参考。`main.tex` 为独立 LaTeX 入口，`main.pdf` 为三页 A4：前两页为原速查内容，第三页为新加入的教材例 1.5.1。用户将自行用小字抄到允许携带的一张 A4 纸上，电子稿不再强制限制为两页。该文件与课程笔记、板书电子转录、习题解答分别维护。

## Scope

按指定范围编排：常见分布及结论、Gamma/Beta 函数、教材五类共轭先验、三种信息、贝叶斯假设、后验加权关系与精度相加、后验估计及 MSE、常用充分统计量、倒 Gamma 与卡方变换及可信上限、后验预测步骤、假设检验三种情形，以及教材例 1.5.1 的正态均值与方差均未知模型。

共轭先验覆盖教材表 1.3.1 的二项、泊松、指数、正态均值和正态方差五类模型；为配合该表，常见分布同时列出泊松与指数。分布公式保留支持集、参数化方式及矩存在条件。MSE 明确区分后验误差和频率误差。

例 1.5.1 包括似然、联合先验、配方与参数更新、联合后验分解、均值的边际 t 后验及相关矩，并把已有的倒 Gamma 可信上限公式代入本例。没有加入超参数确定、HPD 区间、似然原理等其他未授权专题。本版不宣称覆盖两章所有可能考点。

## Notation

符号按所在模型重复使用，不为全篇统一消歧另造替代变量。例如二项分布使用 `n, theta, x`，正态方差直接使用 `sigma^2`，均匀分布使用 `U(a,b)`，Gamma 使用 `alpha, lambda`，Beta 使用 `alpha, beta`。MSE 的估计值记为带帽的 `theta`。积分变量沿用 `x` 或 `theta`。联合正态模型保留教材和板书的 `mu, sigma^2, mu_0, kappa_0, nu_0, sigma_0^2`。

采用与课堂密度一致的 Gamma **率参数化**：`Ga(alpha,lambda)` 的密度为 `lambda^alpha x^(alpha-1) exp(-lambda*x) / Gamma(alpha)`，均值为 `alpha/lambda`。教材部分文字称第二参数为“尺度”，本版按实际密度明确写成“率”，防止混用。

“贝叶斯假设”限定为教材成功概率的 `U(0,1)` 先验；不推广为所有参数都必须取均匀先验。所有可信限统一使用左侧概率分位数：`P(Y <= q_p) = p`。倒 Gamma 一节沿用 `IGa(alpha,beta)`，可信水平写作 `1-gamma`；上限使用卡方的 `gamma` 分位数，下限使用 `1-gamma` 分位数。

这是考试复习速查纸，公式按数学意义核对，不沿用板书电子转录中专为保真而保留的漏项或笔误。

## Build and print

Use XeLaTeX:

```sh
latexmk -xelatex -interaction=nonstopmode -halt-on-error main.tex
```

PDF 当前为三页、A4 纵向。黑白双栏，正文 9 pt，左右边距 9 mm，上下边距 8 mm。打印选择 **A4、实际大小 / 100%**；如选择双面、长边翻转，将需要两张纸。这是手抄参考稿，不是可直接带入考场的一张纸成品。

修改公式或字号后应重新确认没有栏内溢出、截断或缺字；按用户要求，不因页数而删减公式或强行缩小文字。
