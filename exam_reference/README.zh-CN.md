# 考试速查稿

[English](README.md)

这是《贝叶斯统计》第一、二章的公式速查稿。PDF 共三页 A4：前两页为公式汇总，第三页为教材中的正态均值与方差均未知联合模型。它用于复习和手抄参考，不是压缩成一页的考场成品。

## 范围

内容包括常见分布与 Gamma/Beta 函数、共轭先验、三种信息、后验加权均值与精度相加、后验估计与 MSE、充分统计量、倒 Gamma 与卡方变换及可信限、假设检验三种情形、后验预测和正态联合模型。

五类共轭先验按教材表 1.3.1 编排，包括二项、泊松、指数、正态均值和正态方差。分布公式保留支持集、参数化方式及矩存在条件，并区分后验 MSE 和频率 MSE。

教材例 1.5.1 包括似然、联合先验、配方与参数更新、联合后验分解、均值的边际 t 后验、相关矩和方差可信上限。本稿不包含超参数确定、HPD 区间或似然原理，也不宣称覆盖两章所有考点。

各模型内沿用教材和板书记号，不为全篇消歧另造替代变量。联合正态模型保留 `mu, sigma^2, mu_0, kappa_0, nu_0, sigma_0^2`。

`Ga(alpha,lambda)` 采用**率参数化**：密度为 `lambda^alpha x^(alpha-1) exp(-lambda*x) / Gamma(alpha)`，均值为 `alpha/lambda`。教材部分文字称第二参数为“尺度”，这里按实际密度写成“率”，避免混用。

“贝叶斯假设”仅指成功概率的 `U(0,1)` 先验，不推广为所有参数都取均匀先验。分位数统一为左侧概率：`P(Y <= q_p) = p`。倒 Gamma 记为 `IGa(alpha,beta)`，可信水平写作 `1-gamma`；上限使用卡方的 `gamma` 分位数，下限使用 `1-gamma` 分位数。

速查稿按数学意义核对公式，不沿用忠实转录中为保真而保留的板书漏项或笔误。

## 编译

在本目录运行：

```sh
latexmk -xelatex -interaction=nonstopmode -halt-on-error main.tex
```

需要 XeLaTeX、`ctex` 和 Windows 中文字体；`main.tex` 显式指定了 `fontset=windows`。其他系统需改成可用的字体集，例如 TeX Live 的 `fandol`，并检查重新编译的排版。

PDF 为 A4 纵向黑白双栏，正文 9 pt，左右边距 9 mm，上下边距 8 mm。打印选择 A4、实际大小 / 100%；三页双面打印需要两张纸。修改字体或公式后需检查溢出、截断和缺字，不为限制页数而删减公式。
